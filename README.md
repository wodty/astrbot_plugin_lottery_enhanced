## 🤝 介绍

抽奖插件，支持动态奖品类目、等级限制、满人自动开奖、定时自动开奖、批量抽奖。

### v2.3 新特性

- **动态奖品类目**：管理员可随时添加、删除、修改奖品类目，不再局限于固定等级
- **自定义奖品**：每个类目可设置自定义奖品名称和数量
- **等级限制**：可设置群等级/身份要求，不满足的群友无法参加
- **满人自动开奖**：参与人数达到设定值后自动开奖
- **定时自动开奖**：到指定时间自动开奖
- **参加反馈**：参加抽奖后有明确的成功/失败反馈
- **详情查询**：可查询奖品、时间、人数、完整参与名单
- **批量抽奖**：先报名后开奖模式，从所有参与者中随机抽取各等级奖项

## 📦 安装

在 AstrBot 的插件市场搜索 `astrbot_plugin_lottery_enhanced`，点击安装即可。

## ⚙️ 插件配置

在 AstrBot 管理面板 → 插件管理 → 抽奖插件 → 配置 中设置：

### 默认奖品配置（prize_config）

配置默认的 3 个奖项等级（与转盘设计对应），每个可设置奖品名称、数量和转盘颜色。可通过「抽奖配置」命令查看。

> **注意**：开启抽奖时不会自动加载这些默认奖品，管理员需要通过「添加奖品」命令手动设置每次抽奖的奖项。此配置仅作为「抽奖配置」命令展示和未来扩展使用。

| 配置项 | 说明 |
| --- | --- |
| 奖品名称 | 该等级的奖品名称（如 iPhone15、蓝牙耳机） |
| 奖品数量 | 该等级的奖品数量 |
| 转盘颜色 | 该等级在转盘中的对应颜色（设计参考色） |

> 运行时可通过「添加奖品」「删除奖品」命令动态增减类目，不受此配置限制。

### 抽奖设置（lottery_settings）

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 默认满人开奖人数 | 开启抽奖时默认的人数上限（0 = 手动开奖） | 0 |
| 默认最低群等级 | 开启抽奖时默认的最低群等级（0 = 不限） | 0 |
| 默认最低身份 | 开启抽奖时默认的最低身份要求 | 不限 |

## ⌨️ 使用说明

### 命令表

#### 管理员命令

| 命令 | 说明 |
| --- | --- |
| `开启抽奖` | 开启抽奖活动（清空所有内容，需先添加奖品才能参与） |
| `开启抽奖 人数50` | 满 50 人自动开奖 |
| `开启抽奖 时间2024-01-01 18:00` | 到时间自动开奖 |
| `开启抽奖 人数50 时间2024-01-01 18:00` | 两个条件，先到先开 |
| `添加奖品 一等奖 iPhone15 2` | 添加新类目「一等奖」，奖品 iPhone15，数量 2 |
| `添加奖品 二等奖 蓝牙耳机 5` | 添加新类目「二等奖」，奖品蓝牙耳机，数量 5 |
| `添加奖品 三等奖 钥匙扣 10` | 添加新类目「三等奖」，奖品钥匙扣，数量 10 |
| `删除奖品 三等奖` | 删除「三等奖」类目 |
| `设置奖品 一等奖 iPhone15 2` | 修改「一等奖」的奖品名称为 iPhone15，数量 2 |
| `设置奖品 幸运奖 公仔 20` | 修改「幸运奖」的奖品名称为公仔，数量 20 |
| `设置等级 5` | 设置最低群等级 Lv.5 |
| `设置等级 管理员` | 设置最低身份为管理员 |
| `设置等级 取消` | 取消等级限制 |
| `开奖` | 手动开奖 |
| `关闭抽奖` | 关闭抽奖活动 |
| `重置抽奖` | 重置本群抽奖活动 |
| `抽奖配置` | 查看所有抽奖插件配置（奖品模板、默认设置） |

#### 用户命令

| 命令 | 说明 |
| --- | --- |
| `参加抽奖` | 参加当前抽奖 |
| `抽奖` | 参加抽奖（兼容旧命令） |
| `抽奖状态` | 查看活动状态、剩余奖品 |
| `抽奖详情` | 查看奖品、时间、人数、参与名单 |
| `中奖名单` | 查看中奖名单 |

### 使用流程

1. 管理员发送 `开启抽奖 人数50` 开启活动（此时奖品为空，需先添加）
2. 管理员发送 `添加奖品 一等奖 iPhone15 2` 添加奖项（必须，至少一个）
3. 管理员发送 `添加奖品 二等奖 蓝牙耳机 5` 继续添加（可选）
4. 管理员发送 `设置等级 5` 设置参与门槛（可选）
5. 群友发送 `参加抽奖` 参与（奖品未添加时无法参与）
6. 满 50 人自动开奖，也可管理员手动 `开奖`
7. 发送 `抽奖详情` 查看完整信息，`中奖名单` 查看结果

### 默认奖项等级

| 等级 | Emoji | 默认奖品 | 默认数量 | 转盘颜色 |
| --- | --- | --- | --- | --- |
| 一等奖 | 🥇 | U盘 | 3 | `#D91E1C`（红） |
| 二等奖 | 🥈 | 小风扇 | 5 | `#007CC2`（蓝） |
| 三等奖 | 🥉 | 钥匙扣 | 10 | `#DD167B`（粉） |

> 以上为配置中的默认值，与转盘 logo 的色块一一对应。运行时可随时通过命令添加自定义类目（如「幸运奖」「特别奖」等），自定义类目默认使用 🏆 作为图标。

> **注意**：v2.2 采用批量开奖模式，按奖品数量从参与者中随机抽取。开奖顺序按类目添加顺序从高到低依次抽取。
